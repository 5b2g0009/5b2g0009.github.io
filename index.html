Profile

關於我

我是南臺科技大學的學生，對前端網頁開發、使用者介面設計 (UI/UX) 以及網頁遊戲開發有著濃厚的興趣。

在網頁開發的世界裡，我追求乾淨的程式碼與精美的視覺設計。我深信好的使用者體驗源自於對細節的雕琢——無論是精確的邊框、適度的留白，或是流暢的微動畫。

本學期我專注於提升 JavaScript 的互動邏輯開發能力，並嘗試將物理引擎概念融入網頁中，完成了我的期末專題「水果遊戲」。

核心技能標籤

HTML5 / CSS3 JavaScript ES6 響應式網頁設計 (RWD) 網頁遊戲邏輯 UI/UX 視覺設計 物理引擎應用 Git 程式版本控制
Featured Project

期末專題成果

期末專題推薦

水果切切樂遊戲 (Fruit Ninja)

本學期的重磅期末專案。這是一個網頁版的水果忍者割切遊戲，玩家需要滑動滑鼠或在觸控螢幕上劃過畫面，將飛出的水果一刀兩斷以獲取分數，並同時避開混雜在其中的炸彈。遊戲具有流暢的刀光特效、逼真的水果分裂物理效果，以及刺激的連擊得分機制！

  • HTML5 Canvas
  • 刀光特效與物理分裂
  • RWD 支援與觸控優化

Semester Journey

本學期上課內容

Course 01

JavaScript 語言基礎與核心物件

掌握變數、流程控制、語法邏輯，並熟練 String、Math 與 Array 等常用內建資料物件。

  • JavaScript 歷史概述與 ECMAScript 標準。
  • 變數宣告（let, const）、資料型態與流程控制語法。
  • String、Math 與 Array 等核心資料物件的高階操作。
Course 02

物件導向程式設計與文字處理

深入理解 JavaScript 以物件為基礎的特性，並掌握強大的文字驗證技術。

  • 物件字面值、建構函式與原型鏈（Prototype）概念。
  • 理解執行環境中的 this 關鍵字指向與綁定。
  • 常規表示式（Regular Expression）語法與表單欄位驗證。
Course 03

DOM 與 BOM 網頁元素動態操控

掌握瀏覽器與文件物件模型，實現網頁元素與樣式的動態操控。

  • Window 頂層物件、計時器與 BOM 瀏覽器操控。
  • Document 節點樹的選取、動態建立、刪除與修改。
  • style / styleSheet 物件操控與網頁元素座標定位。
Course 04

網頁互動事件處理與異常防禦

深入理解網頁事件監聽機制，並學習如何打造健全的錯誤處理流程。

  • 常見互動事件監聽、事件物件（Event）的屬性與應用。
  • 理解事件流機制：事件冒泡（Bubbling）與捕獲（Capture）。
  • 使用 try...catch 進行異常處理與嚴格模式（use strict）除錯。
